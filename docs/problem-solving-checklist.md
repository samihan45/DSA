# Problem-solving checklist

## Understand
- [ ] Restate the problem in my own words.
- [ ] Identify input size, constraints, and expected output.
- [ ] Work through a small example by hand.
- [ ] Consider empty input, one element, duplicates, negatives, and boundaries.

## Solve
- [ ] Think of a straightforward approach first.
- [ ] Identify a useful pattern or data structure.
- [ ] Explain why the approach is correct.
- [ ] Estimate time and auxiliary space.
- [ ] Test normal and edge cases.

## Review
- [ ] Check off-by-one conditions and integer bounds.
- [ ] Remove unnecessary work without hurting readability.
- [ ] Record the key observation.
- [ ] Revisit later without looking at the solution.
